## Prerequisites

- A GitHub account
- At least one repository with a `package.json`

## Quick Start

1. Go to [patchboard.vercel.app](https://patchboard.vercel.app) and sign in with GitHub
2. Click **Add Project** and select a repository
3. Click **Sync** to run your first dependency scan
4. Review outdated packages — approve or snooze each one
5. Click **Open PR** to raise a pull request with all approved updates
