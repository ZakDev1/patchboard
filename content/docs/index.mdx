## What is Patchboard?

Patchboard monitors your GitHub repositories for outdated dependencies. 
Connect a repo, run a scan, and review every outdated package before 
raising a single pull request with all your changes.

## Features

- **Instant scanning** — compare your dependencies against the npm registry in seconds
- **Review workflow** — approve or snooze each update individually
- **Snapshot history** — track how your dependency health changes over time
- **One-click PRs** — raise a single pull request with all approved updates
- **Weekly digests** — automated email summaries every Monday
- **Pro plan** — unlimited repos with Stripe billing
