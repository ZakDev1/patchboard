## v1.1.0 - June 2026

### Features
- Automated weekly dependency scans via Trigger.dev
- Resend email digests for Pro users  
- Stripe billing with Free and Pro plans
- Migrated database queries to Drizzle ORM

### Observability
- Added Sentry error tracking and performance monitoring
- Added PostHog analytics with custom events
- Added PostHog and Stripe data warehouse integration

### Developer experience
- Added Vitest unit tests with CI Postgres service
- Added Playwright E2E tests
- GitHub Actions CI pipeline running both test suites on every push
- Fumadocs documentation site at /docs
